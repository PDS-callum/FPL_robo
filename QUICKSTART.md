# FPL Platform - Quick Start ⚡

Get started with the FPL Platform in 5 minutes!

---

## 🚀 Installation (2 minutes)

```bash
# 1. Clone or navigate to repository
cd FPL_robo

# 2. Install dependencies
pip install -r requirements.txt
```

---

## 🎮 Launch Platform (30 seconds)

```bash
python run_platform.py
```

**Platform URL:** http://127.0.0.1:5001

---

## 👤 First Time Setup (2 minutes)

### Step 1: Register (30 seconds)

1. Go to http://127.0.0.1:5001/auth/register
2. Fill in:
   - Username
   - Email
   - Password (min 6 chars)
3. Click "Register"

### Step 2: Login (15 seconds)

1. Go to http://127.0.0.1:5001/auth/login
2. Enter username/email and password
3. Click "Login"

### Step 3: Add Team (45 seconds)

1. Click "My Teams" → "Add Team"
2. Enter your FPL Manager ID
   - Find at: `fantasy.premierleague.com/entry/[YOUR_ID]/event/1`
   - Example: `789800`
3. Click "Add Team"

### Step 4: Run Analysis (30 seconds)

1. From dashboard, click "Run Bot Analysis"
2. Click "Run Bot Analysis" button
3. Wait 10-30 seconds
4. View your results!

---

## ⚙️ Optional: Configure Bot

1. Go to "My Teams"
2. Select team → "Settings"
3. Adjust:
   - **Risk Aversion** (0=aggressive, 1=conservative)
   - **Min Playing Chance** (filter doubtful players)
   - **Analyze Wildcard** (slower but includes wildcard timing)
   - **Prevent Hits** (only free transfers)

---

## 🔄 Weekly Workflow

**Every week before deadline:**

1. Login to platform
2. Click "Run Bot Analysis" on your primary team
3. Wait for analysis to complete
4. Review recommendations:
   - Check current week transfers
   - See captain suggestion
   - Review 7-week plan
5. Make your transfers in FPL
6. Set your captain

**That's it!** ✨
