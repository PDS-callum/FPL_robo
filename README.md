# FPL Robo

Personal Fantasy Premier League (FPL) automation project. Season builds of the bot live on dedicated branches so each year’s code stays intact while newer seasons can be rebuilt from scratch.

## Season branches

| Branch | Purpose |
|--------|---------|
| [`2025-2026`](https://github.com/PDS-callum/FPL_robo/tree/2025-2026) | Complete bot + platform used for the 2025/26 FPL season |
| [`2026-2027`](https://github.com/PDS-callum/FPL_robo/tree/2026-2027) | Clean slate for the 2026/27 rebuild |

`main` holds this overview only. Check out a season branch to work with that year’s code.
