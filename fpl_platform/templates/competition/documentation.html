Overview

The FPL Bot Competition allows you to create your own automated Fantasy Premier League bot that competes against other users' bots. Your bot will make decisions about transfers, captaincy, and team selection based on the data provided.

Bots are evaluated on their performance in the current FPL season, with rankings updated after each gameweek.

Requirements

Your bot must meet the following requirements:

  • Written in Python
  • Implement the required interface methods
  • Pass validation checks
  • Not use restricted imports or functions
  • Execute within reasonable time limits

Bot Interface

Your bot class must implement these two methods:

1. analyze(data)

Analyzes the current team and game state.

def analyze(self, data):
    """
    Analyze the current team and FPL data
    
    Parameters:
        data (dict): Contains current team, player stats, fixtures, etc.

        dict: Analysis results with insights and recommendations
    """
    return {
        'status': 'ok',
        'message': 'Analysis complete',
        'insights': []

Example Bot

Here's a simple example bot to get you started:

class SimpleFPLBot:
    """
    A simple FPL bot that makes basic decisions
    """
    
    def __init__(self):
        self.team = []
        self.budget = 100.0
    
    def analyze(self, data):
        """Analyze current team"""
        current_team = data.get('current_team', [])
        
        # Calculate team statistics
        total_value = sum(player.get('cost', 0) for player in current_team)
        
        return {
            'status': 'ok',
            'message': f'Team analyzed. Total value: £{total_value}m',
            'insights': [
                'Consider transfers for injured players',
                'Look for players with good fixtures'
            ]
        }
    
    def optimize(self, data):
        """Optimize team and make transfers"""
        current_team = data.get('current_team', [])
        all_players = data.get('all_players', [])
        
        # Sort players by expected points
        sorted_players = sorted(
            all_players, 
            key=lambda x: x.get('expected_points', 0),
            reverse=True
        )
        
        # Select captain (highest expected points)
        captain_id = sorted_players[0]['id'] if sorted_players else None
        vice_captain_id = sorted_players[1]['id'] if len(sorted_players) > 1 else None
        
        # Simple transfer logic: replace lowest scorer
        transfers = []
        if len(current_team) > 0:
            worst_player = min(current_team, key=lambda x: x.get('points', 0))
            best_available = sorted_players[0]
            
            if best_available['id'] not in [p['id'] for p in current_team]:
                transfers.append({
                    'out': worst_player['id'],
                    'in': best_available['id']
                })
        
        return {
            'transfers': transfers,
            'captain': captain_id,
            'vice_captain': vice_captain_id,
            'lineup': [p['id'] for p in current_team[:11]]
        }

Testing Your Bot

Before activating your bot for the current season, you should:

  1. Submit your bot for validation
  2. Run backtests on previous seasons to see how it performs
  3. Analyze the backtest results to identify weaknesses
  4. Iterate on your bot's strategy
  5. Activate when you're confident in its performance
Tip: Backtests help you understand how your bot would have performed on historical data without risking your competition ranking.

Security Restrictions

For security reasons, the following are not allowed in bot code:

  • File system access (open, file)
  • System operations (os, subprocess, sys)
  • Dynamic code execution (eval, exec, compile)
  • Module imports (__import__)
  • User input (input, raw_input)

Your bot runs in a sandboxed environment with access to:

  • Basic Python built-ins (list, dict, str, int, float, etc.)
  • Standard operations (print, len, range, sum, min, max, etc.)
  • Data structures and algorithms

Competition Rules

  • Each user can have one active bot per season
  • Bots are executed automatically each gameweek
  • Rankings are based on total points accumulated
  • Standard FPL rules apply (transfers, hits, chips, etc.)
  • Bots must complete execution within time limits
  • Code can be updated, but changes require re-activation
